# Бот оформления Telegram-канала и предложки с отдельными диалогами

Готовый бот для публикации и живого обновления закреплённого приветственного поста в Telegram-канале с **цветными кастомными кнопками** (`YouTube`, `Twitch`, `Чат в ТГ`, `Предложка`) и **личной предложкой**, где для каждого подписчика автоматически создаётся **отдельный чат-ветка (тема)**.

## Возможности
- **Закреплённый приветственный пост**: HTML-форматирование + опциональная обложка (баннер).
- **Кастомный стиль кнопок (Telegram Bot API)**:
  - 🔴 `danger` (красная — по умолчанию стоит на **YouTube**)
  - 🔵 `primary` (синяя — по умолчанию стоит на **Чат в ТГ**)
  - 🟢 `success` (зелёная — по умолчанию стоит на **Предложка**)
  - ⚪ `default` (стандартная полупрозрачная — стоит на **🟣 Twitch**)
  - Опционально: `icon_custom_emoji_id` (иконка из кастомного эмодзи перед текстом кнопки) и удобная группировка по рядам.
- **Гибкое редактирование прямо в Telegram (`/admin`)**:
  - Добавить/удалить/переместить любую кнопку, поменять ссылку, текст, цвет и ряд.
  - Изменить текст поста или обложку.
  - Нажать **«🔄 Обновить закреплённый пост»**, и ссылки/кнопки обновятся прямо в существующем посте канала без его удаления.
- **Предложка с отдельными диалогами с каждым пользователем**:
  - Поддерживается режим **Форум-тем (`FEEDBACK_GROUP_ID`)**: в вашей закрытой группе с включёнными темами бот создаёт **отдельную тему под каждого подписчика**. Вы переписываетесь с каждым в его собственной ветке, ваш личный аккаунт скрыт, а годные посты можно отправить в канал в 1 клик кнопкой **«📤 Опубликовать в канал»**.
  - Если группу не указывать — работает запасной режим через ЛС с ботом (ответ через `Reply`).

## Быстрая настройка (5 минут)

### 1. Создайте бота
1. Откройте `@BotFather` в Telegram, отправьте `/newbot`, придумайте имя и `@username` бота.
2. Скопируйте полученный токен.
3. Добавьте бота **администратором в ваш канал** с правами:
   - публикация сообщений (`Post Messages`)
   - изменение сообщений (`Edit Messages`)
   - закрепление сообщений (`Pin Messages`)

### 2. Настройте группу для отдельных диалогов предложки (рекомендуется)
1. Создайте новую **закрытую группу** в Telegram (только вы).
2. В настройках группы включите **«Темы» (Topics)**.
3. Добавьте туда вашего бота и выдайте ему права администратора (**Управление темами**, **Отправка/закрепление сообщений**).
4. После запуска бота напишите `/id` в этой группе — бот покажет её ID (например `-1001234567890`).

*(Альтернатива без сервера 24/7: если вы включите встроенные в Telegram **«Сообщения каналу» (Direct Messages)** в настройках вашего канала, то можете просто поменять ссылку на кнопке «Предложка» на `https://t.me/ваш_канал?direct`, а бота запускать с ПК только тогда, когда нужно опубликовать или обновить кнопки в посте.)*

### 3. Заполните `.env`
Скопируйте `.env.example` в `.env` и заполните значения:
```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_IDS=ваш_числовой_telegram_id
CHANNEL_ID=@ваш_канал
FEEDBACK_GROUP_ID=-100ваш_id_форум_группы
```

### 4. Запустите бота
Двойным кликом по `run.bat` или через терминал:
```powershell
uv run python -m app.main
```

После запуска откройте личный чат с ботом и отправьте **`/admin`**:
1. Зайдите в **«🔘 Кнопки и стили»** и подставьте свои ссылки на YouTube, Twitch и Чат ТГ.
2. При желании измените приветственный текст или добавьте картинку-обложку.
3. Нажмите **«👁 Предпросмотр поста»** для проверки, а затем **«📢 Опубликовать и закрепить заново»**.

## Mini App-визитка с хромовыми кнопками и «водяной волной» (`docs/`)

В папке `docs/` лежит готовый **Telegram Mini App** для GitHub Pages:
- [docs/index.html](docs/index.html) — визитка канала (фото, текст, кнопки с хромовым переливанием, фото под стеклом, угловая кнопка-звёздочка и водяная рябь при клике).
- [docs/editor.html](docs/editor.html) — визуальный конструктор прямо в браузере (редактирование текста, кнопок, стилей и экспорт `config.json`).
- [docs/config.json](docs/config.json) — конфиг кнопок и ссылок Mini App.

### Как подключить Mini App к боту в Telegram
1. Включите GitHub Pages в настройках репозитория (**Settings → Pages → Deploy from branch → `main` / `/docs`**).
2. Откройте `@BotFather` → отправьте `/newapp` → выберите вашего бота → укажите название, описание, иконку и URL вашего сайта GitHub Pages (`https://<username>.github.io/<repo>/`).
3. Задайте короткое имя приложения (например `menu`) — `@BotFather` выдаст ссылку `https://t.me/<ваш_бот>/menu`.
4. В боте откройте `/admin` → **«🔘 Кнопки и стили»** → **«✨ Кнопка Mini App»** и введите `menu` (или готовую ссылку), после чего обновите закреплённый пост.
